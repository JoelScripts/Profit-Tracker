# Hypixel SkyBlock Profit Tracker

Monitors BIN items on the Hypixel SkyBlock Auction House, identifies profitable items and notifies you in game.

# Overview

This project will create an application that will monitor the Hypixel SkyBlock Auction House. It will:
Monitor BIN items in real time.
Identify profitable flipping items.
Calculate the risk involved with each item.

Notify you in game.

Not rely on the Minecraft client.
# Features
Auction Monitoring - Monitor BIN items in real time.
Deal Spotter - Uses advanced algorithms to spot profitable flips.
Profit Calculator - Calculate profits and ROIs.
Risk Calculator - Calculates the risk of each item (1-10).
In Game Notifier - Sends notifications in game via a client mod.
# Architecture
The application has been designed with multiple components:
Market Data Provider
